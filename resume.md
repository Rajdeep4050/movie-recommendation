
## Project Highlights

- Architected an end-to-end NLP-driven movie recommendation system supporting 100K+ title catalogue with sub-millisecond query latency.
- Implemented TF-IDF feature extraction with sparse matrix optimization for efficient text representation and similarity computation.
- Applied SVD dimensionality reduction to reduce feature space while preserving semantic relationships and retrieval quality.
- Engineered text preprocessing pipelines with normalization, tokenization, and n-gram extraction to standardize noisy user queries.
- Integrated fuzzy string matching algorithms to handle typos and variant spellings, improving query recall by 15-20%.
- Designed offline evaluation framework using Recall@k and NDCG metrics to quantify model quality and validate recommendation relevance.
- Implemented production-grade model serialization (NPZ, Parquet, JSON) with artifact versioning for reproducibility and rollback capabilities.
- Optimized inference serving layer using cosine similarity on sparse vectors for low-latency, real-time recommendation retrieval.
- Automated weekly model retraining and deployment using a 10-step Apache Airflow orchestration pipeline with data validation and quality checks.
- Containerized entire system with Docker for consistent deployment across development, staging, and production environments.
